MyTube

Install it. Pin it. Open it.

Use this guide in the browser where you want MyTube. Each browser needs its own installation. This Windows preview includes an extension and a local companion.

1. Prepare this computer

Install Node.js 22 or newer, then double-click MyTube.cmd in this folder. It builds the extension and opens YouTube key setup. Enter your personal key only in the protected Windows window. Keep the launcher running.

Your YouTube key and ChatGPT sign-in are separate. Setup explains how to create a key; nothing needs to be pasted into a chat.

2. Add MyTube to your browser

Choose your browser below. Paste the indicated address into its address bar.

Microsoft Edge
  1. Open edge://extensions and enable Developer mode.
  2. Click Load unpacked and select dist\brave inside this folder. The Chromium package works with Edge too.
  3. The welcome guide opens. Copy its connection ID into the launcher prompt.
  4. Open the puzzle-piece Extensions menu, find MyTube Local Preview, then choose Show in toolbar (the eye icon or the … menu).
Google Chrome
  1. Open chrome://extensions and enable Developer mode.
  2. Click Load unpacked and select dist\brave inside this folder.
  3. The welcome guide opens. Copy its connection ID into the launcher prompt.
  4. Open the puzzle-piece Extensions menu and click the pin next to MyTube Local Preview.
Brave
  1. Open brave://extensions and enable Developer mode.
  2. Click Load unpacked and select dist\brave inside this folder.
  3. The welcome guide opens. Copy its connection ID into the launcher prompt.
  4. Open the puzzle-piece Extensions menu and click the pin next to MyTube Local Preview.
Firefox
  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and select dist\firefox\manifest.json.
  3. The welcome guide opens. Copy its moz-extension://… connection address into the launcher prompt. Allow the requested site permissions.
  4. Open the puzzle-piece Extensions menu, click the gear next to MyTube Local Preview, then Pin to Toolbar.

Temporary add-ons disappear when Firefox closes. Load the same manifest again to use this preview. Regular installation requires Mozilla signing; optional Google subscriptions are not available on Firefox.

3. Open MyTube

Choose Open MyTube now in the welcome guide, or click the blue toolbar icon. You can also try Alt + Shift + M. If that shortcut is already used, assign a different one in the browser’s extension shortcut settings.

Once MyTube is open, press Ctrl + D to bookmark it. In MyTube, Settings → Setup & browser access brings you back to the guide.

For later visits, start MyTube.cmd, then use your icon, shortcut or bookmark.

Already installed, but cannot connect?

Only one browser installation is connected to the companion at a time. To switch browsers, close the existing launcher, open a terminal in this folder and run npm start -- --configure. Paste the connection ID shown by MyTube in the browser you want to use.

After updates, reload the existing extension in its browser’s extension manager and reopen MyTube. Do not uninstall it: that can erase saved browser data.
