    1. Connect this computer

      MyTube uses a local companion to keep your YouTube key protected on Windows and handle ChatGPT sign-in.

      Checking the companion…

      Set up the companion or fix the connection

      This preview still requires Node.js 22+ and the MyTube project folder. Open MyTube.cmd in that folder and leave it running.

      When the launcher asks for the extension ID or Firefox connection address, use this value:

      This identifies this browser installation; it is not an API key. If the launcher already remembers a different browser or ID, close it and run npm start -- --configure from the project folder. Only the configured browser installation can connect at a time.

      In Firefox, allow the requested site permissions for MyTube in the add-on settings. If you reinstall the add-on or change profiles, configure the launcher again with the address shown here.

    2. Connect YouTube

      Your personal API key enables YouTube searches. Enter it only in the protected Windows window.

      Waiting for the companion.

      Get a personal YouTube key

      In Google Cloud, select or create a project and enable YouTube Data API v3. Under Credentials, create an API key and restrict it to YouTube Data API v3. Save it in the Windows window, then check the connection again.

      The key stays on this computer. A saved key still needs a successful search to confirm Google accepts it.

    3. Sign in to ChatGPT

      ChatGPT helps interpret your request. This sign-in is separate from your YouTube key; your account must have access to the service MyTube uses.
